# ICFES Platform

Plataforma web educativa para apoyar la preparación de estudiantes
de grados 9°, 10° y 11° para las pruebas Saber 11°.

## Tecnologías

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap
- JavaScript
- XAMPP
- Git
- GitHub

## Público objetivo

Estudiantes de una Institución Pública Departamental
de Cundinamarca, Colombia.

## Funcionalidades

- Autenticación
- Dashboard
- Recursos educativos
- Evaluaciones
- Simulacros
- Seguimiento del progreso
- Gamificación
- Avatares
- Insignias
- Sistema de puntos
- Buzón de sugerencias
- Administración de estudiantes
